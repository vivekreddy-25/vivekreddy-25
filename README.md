## Featured projects

### [human-in-the-loop-email-agent](https://github.com/vivekreddy-25/human-in-the-loop-email-agent)
An email assistant built with LangGraph. It retrieves context with RAG, drafts an email, and waits for human approval (approve, edit or reject) before anything is sent.
`LangGraph` `RAG` `Ollama` `Qdrant`

### [fake-news-spread-simulation](https://github.com/vivekreddy-25/fake-news-spread-simulation)
Human behavior modeling and simulation: how fake news spreads through a network of rule-based and LLM agents, and which interventions slow it down.
`Agent-based modeling` `LLM agents` `Ollama` `Streamlit`

### [guarded-coding-assistant](https://github.com/vivekreddy-25/guarded-coding-assistant)
A coding assistant protected with NVIDIA NeMo Guardrails. It blocks unsafe prompts and leaked secrets, and is tested on a benchmark prompt set.
`NeMo Guardrails` `Groq API`

### [multi-source-rag-chatbot](https://github.com/vivekreddy-25/multi-source-rag-chatbot)
A telecom customer-support chatbot that merges FAQ, ticket and PDF retrieval, running fully locally.
`RAG` `Ollama` `FAISS`
